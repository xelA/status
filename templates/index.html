What the metrics mean

WebSocket

The real-time latency of the persistent WebSocket connection between {{ bot.username }} and the API. Unlike REST, the connection stays open, which makes it a good measure of stability and responsiveness, similar to in-game latency.

REST

The total round-trip time for {{ bot.username }} to send an HTTP request to the API and get a response back. It shows how quickly the bot can talk to the API over standard web requests.

Discord

A latency metric published by Discord themselves, estimating the delay between their servers and the API. Since Discord has internal network insight, it's a useful reference to compare the other two against.

For the nerds

This page lets you check that the bot is running smoothly, and whether your internet is shit or Discord is drunk yet again. Want the raw JSON behind it? Use /api?show=latest.

Valid show values are latest, history, window, daily and user. Separate several with a comma, for example latest,user.
